# React 電卓アプリ

課題用の独立したVite + Reactプロジェクトです。

## 起動する

```bash
cd /Users/hutami/practice/react-calculator-app/react-calculator-app
npm install
npm run dev
```

この環境ではインストール済みなので、通常は `cd` と `npm run dev` だけで起動できます。
ターミナルの `Local:` に表示されたURLを開いてください。終了は `Ctrl + C` です。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| src/main.jsx | HTMLのrootにReactのAppを表示する入口 |
| src/App.jsx | Calculatorコンポーネントを呼び出す |
| src/Calculator.jsx | 状態管理・入力処理・計算・ボタンの表示 |
| src/App.css | 電卓の色、サイズ、4列のボタン配置 |
| src/index.css | ページ全体のフォントや背景 |

コンポーネントとは、画面の部品を返す関数です。今回の `Calculator` は電卓全体を1つの部品にしています。

## 1. useStateで表示内容を覚える

```jsx
const [display, setDisplay] = useState('')
```

- `display`：現在の表示内容を保存する変数です。
- `setDisplay`：その内容を更新する関数です。更新するとReactが画面に反映します。
- `useState('')`：最初の値を空文字にします。

`display` は数字も含めて文字列として扱います。例えば「1」「2」と押したとき、足し算の3ではなく、文字をつないだ `'12'` を作るためです。

```jsx
{display || '0'}
```

画面上だけ、空文字の場合は0を表示します。内部の値は空文字のままなので、最初に1を押すと `'01'` ではなく `'1'` になります。文字列の `'0'` は空文字とは異なり、そのまま表示されます。

## 2. handleClickでボタンの処理を分ける

| ボタン | 処理 |
| --- | --- |
| C | `setDisplay('')` で空にする |
| = | `calculate(display)` で計算し、結果を表示する |
| 数字・演算子 | 現在の文字列の末尾に追加する |

```jsx
setDisplay((previousDisplay) => previousDisplay + btn)
```

`previousDisplay` は更新前の値です。例えば表示が `'12'`、押したボタンが `'+'` なら、次の値は `'12+'` になります。

`=` の処理では、`try` 内で計算を試し、計算中に例外が発生すると `catch` に進んで「エラー」を表示します。計算結果は数値なので、`String()` で文字列に戻して保存します。

## 3. calculateで式を調べ、計算する

```js
const validExpression = /^(\d+)([+\-*/])(\d+)$/
const match = expression.match(validExpression)
```

正規表現とは、文字列の形を調べるためのパターンです。

| 部分 | 意味 |
| --- | --- |
| `^` | 文字列の先頭 |
| `(\d+)` | 数字が1文字以上続く部分を取り出す |
| `([+\-*/])` | +、-、*、/のいずれか1文字を取り出す |
| `(\d+)` | もう一方の数字のまとまりを取り出す |
| `$` | 文字列の末尾 |

`\d+` の `+` は「1回以上」の意味です。角括弧の中の `+` は足し算記号そのものです。

例えば `'12+3'` に対する `match` は次の配列になります。

```js
['12+3', '12', '+', '3']
// 全体      [1]  [2]  [3]
```

`Number(match[1])` と `Number(match[3])` で文字列を数値に変換します。変換しないと、`'12' + '3'` は文字列結合になり `'123'` になってしまいます。

`switch (operator)` で演算子ごとに加算・減算・乗算・除算を実行します。形式が違う場合は `throw new Error(...)` で例外を発生させ、呼び出し元の `catch` で「エラー」にします。

課題の正規表現に合わせて、入力する数値は0以上の整数です。`3-5` の結果として負数を表示したり、`7/2` の結果として小数を表示したりすることはできます。

## 4. mapで16個のボタンを作る

```jsx
{buttons.map((btn) => (
  <button key={btn} onClick={() => handleClick(btn)}>
    {btn}
  </button>
))}
```

`map()` は配列の要素を1つずつ別の形に変換します。今回は `'7'` などの文字列からbutton要素を作ります。

`key` はReactが一覧の要素を識別するための目印です。クリック処理を分岐させるのは `key` ではなく、`handleClick(btn)` に渡す `btn` です。

`onClick={() => handleClick(btn)}` は「クリックされたら実行する関数」を渡しています。`onClick={handleClick(btn)}` と書くと、画面を描いている最中に実行されてしまいます。

## 5. CSSで4列に並べる

```css
.button-grid {
  display: grid;
  grid-template-columns: repeat(4, minmax(0, 1fr));
  gap: 8px;
}
```

`display: grid` で格子状に配置し、`repeat(4, ...)` で4列にします。`1fr` は空いている幅を等しく分ける指定です。`minmax(0, 1fr)` で列を狭い画面でも縮められるようにしています。`gap` はボタン間の余白です。

## 操作の流れ

「1」→「2」→「+」→「3」→「=」と押すと、状態は次の順に変わります。

```text
'' → '1' → '12' → '12+' → '12+3' → '15'
```

ボタンを押す → handleClick → setDisplay → Reactが表示を更新、という流れが基本です。`=` のときだけ途中で `calculate` を呼び出します。

## 仕様上の範囲

- 小数点ボタンはありません。
- `1+2+3`、`123+`、`1+*2`、空の式は「エラー」です。
- 0で割る場合や、安全に扱える数値範囲を超える場合も「エラー」にします。
- 結果やエラーの表示後も数字・演算子は末尾に追加します。新しく計算するときはCで消してください。
- 負数や小数の結果に演算子を続けた式は、課題の正規表現に合わないため「エラー」です。
- 小数の精度はJavaScriptの通常の数値演算に従います。
